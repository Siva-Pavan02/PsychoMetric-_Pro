# User Flow

1. **Landing Page**: Participant learns about the assessment.
2. **Participant Details**: Enters Name, Email, Phone.
3. **Payment Initiation**: Clicks pay, system generates a Razorpay order.
4. **Secure Checkout**: Razorpay modal opens, user pays ₹99.
5. **Verification**: System verifies Razorpay signature and unlocks questions.
6. **Assessment**: User answers 50 questions (5 per page, 10 pages).
7. **Submission**: Answers are scored deterministically.
8. **Report**: User views personalized results on-screen.
9. **PDF Export**: User can download a structured PDF report.
